## 3. Mirror structure, per rule

**Raw** (`renderRaw`). The reference renders `'<span style="white-space: pre-wrap;">' ++ wikidotEscapeRaw(text) ++ '</span>'`, where `wikidotEscapeRaw` is a `strtr` table whose keys are all single bytes (space→`&#32;`, NUL→space, `>`→`&gt;`, `<`→`&lt;`, `&`→`&amp;`, apostrophe→apostrophe literally, `"`→`&quot;`), so the mirror is a per-byte map `wikidotEscapeRawByte` folded over the text bytes. The NUL→space arm is the subtle one (a literal NUL byte in a raw body renders as a plain space, where the surrounding pipeline's placeholder byte is `\xFF`, a different byte entirely); it is pinned by the theorem `escapeRaw_significant_nul`.

**Rawold** (`renderRawold`). Bare `htmlspecialchars($options['text'])` under PHP 8.5 defaults, which is exactly the existing `htmlSpecialCharsQuotesSubst` helper (ENT_QUOTES | ENT_SUBSTITUTE): no wrapper, spaces kept, apostrophes escaped as `&#039;`. No new escape code was written.

**Form** (`renderForm`). A token with `blank` set renders as the empty string; a token with `text` set renders as the Raw span around the `wikidotEscapeRaw` of the line followed by the leading-pair indent transform (while the escaped line starts with the ten bytes `&#32;&#32;`, emit `&nbsp;&#32;` and drop ten; then if it starts with the five bytes `&#32;`, emit `&#32;` and drop five); any other token shape renders as the empty string. The mirror's `formIndentGo` is fuel-bounded with fuel = input length + 1, which strictly exceeds the number of pair steps any input can take (each step consumes ten bytes), so the bound is never the reason a render stops. Form's parse emits one token per line, so no cross-line state exists at render time.

**Heading** (`renderHeading`). Exactly which render-time state this rule reads: only its own token's options, plus two configuration facts that are constant across the whole corpus (the `css_h1..h6` conf values are all null, so no class attribute is ever emitted, and `use_id` is true). It reads no registry, no counter, and no other token: the `toc<N>` ids were assigned at parse time and arrive inside the token. The five token types mirror as: `start` → `"\n<h{level}{idAttr}{onclick}><span>"` where `idAttr` is ` id="{id}"` iff an id option is set and non-empty (the id interpolated raw) and `onclick` is the `hideTOC` attribute iff a `collapse` option is set; `start-notoc` → `"\n<h{level}><span>"` (never an id attribute, even though the token carries an id key whose value is null); `end` → `"</span></h{level}>\n"` plus, iff `collapse` is set, the `{id}__link` anchor line with `[+]` for a truthy collapse and `[-]` otherwise; `startContent` → the `hideTOC` script block (iff `collapse` is set) followed by the `{id}__content` div opener, with `display: none; ` in the style iff collapse is exactly boolean true; `endContent` → `"\n</div>\n"`. One fossil subtlety is mirrored deliberately: the file's static `$jsOutput` flag is read but never assigned, so the script block is emitted for every `startContent` token rather than only the first; the mirror emits it unconditionally in that branch for the same reason. The collapse and content branches are unreachable from the active parse (R4-SCOPE rule 29) but are mirrored anyway so the function is total over the token shapes the fossil renderer accepts.

**Toc** (`renderToc`). Exactly which render-time state this rule reads: its own token's options, the conf values `div_id` (`toc`) and `css_item` (null, hence unused in output), and the class constant `$this->min`, which the fossil initializes to 0 and never writes, so each item's margin is its level in em. The heading registry the brief asked about is parse-side only: the render consumes the `list_start` / `item_start` / `item_end` / `list_end` tokens the parse already produced, and the heading text between item tokens reaches the output as literal text carrying the `üü` marker pair that `renderToc`'s item arms emit and the `RenderCore` post-pass strips. The four types mirror as: `list_start` → (iff `align` is PHP-falsy: the one-cell table wrapper opener) ++ `<div id="toc"` ++ (` class="floatleft"` iff align is `f<`, ` class="floatright"` iff align is `f>`) ++ `>` ++ the fold/unfold action bar ++ `<div class="title">` ++ the title escaped with `htmlspecialchars(..., ENT_COMPAT)` ++ `</div>` ++ `<div id="toc-list">`, where the title is the `attr` map's string `title` entry if present, else `Table of Contents`; `list_end` → `"\n</div></div>"` ++ (iff align falsy: `</td></tr></table>`) ++ `"\n\n"`; `item_start` → `"\n\t<div style=\"margin-left: {level}em;\"><a href=\"#{id}\">"` ++ the `üü` bytes; `item_end` → the `üü` bytes ++ `"</a></div>"`. PHP truthiness is mirrored by `rhTruthy` (falsy: empty, `"0"`, null, false, absent), which the Heading collapse test and the Toc align test share.
