# R5-R2 pre-probe ledger — render-side inline and link rules

Assignment and read basis. This unit hunts the render-side inline and link seam on the post-REFCORR7 canonical base e53e7234, reading the Xhtml render sources under ref-php/text-wiki/Text/Wiki/Render/Xhtml/ for Url, Email, Freelink, Interwiki, Image, Embed, Math and Mathinline plus the shared Xhtml.php escaping bridge, and cross-checking the parse rules that feed those renderers. Every suspicion below is raised before any live probe, with the decisive rule-level CONFIRM byte and CLEAR byte stated in advance. All live behavior is definitional however malformed; intent is never evidence. The standard mask (probe.norm plus the campaign frame mask) sorts attributes and masks per-render ids, newpage class, script bodies and numeric entities, so attribute ORDER is not a confirmable byte in this campaign; title presence, href/target values, span content and error blocks are. Serving-layer surfaces (class="newpage", wdfiles hosts, gallery ids, Stage 2 purifyHtml frames, local--files paths that depend on the page name) are CLEARED by construction and are not counted as rule-level divergences. No Lean elaboration is planned; mirror consequences will be inferred by reading lean-ftml/LeanFtml/ sources only for any confirmed divergence.

Cleared in advance by source reading and by the campaign mask, without a probe byte: the Url `#` to `javascript:;` substitution is unreachable because the Url parse regex requires a recognized scheme; the Url images branch is disabled by wiki-config.php (`url.images=false`) in both harness and resetWiki page mode; the Freelink `site` branch is unreachable after the parse rule removed the `::` convention; the Freelink/Url `nonbr` branch is unreachable because the current parse rule dropped the option; the Interwiki unknown-site render fallback is unreachable because the parse rule returns the whole match; Image local--files paths embed the page name and are serving-layer, which is why all image cases use an external src. Attribute order, `class="newpage"`, Stage 2 frames, token-id digits and wdfiles/gallery hosts are owned classes under the standard mask and are never treated as new divergences.
