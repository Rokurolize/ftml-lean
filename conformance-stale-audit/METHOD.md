# Stale-audit method and reproduction

Scratch reference. `_scratch/` is a byte copy of this tree's `ref-php/` made at the start of the audit. Its `Interwiki.php` hashes to `ca191fa743b7b72bff0a853aeb736039a747c6e6f317046ac58f1a5ff6b10de6` and its four `Url.php` render calls carry `ENT_COMPAT, 'UTF-8'`, i.e. it is the post-ADOPT-CORR / snapshot-25 canonical reference. For each stage tree its own `render-restricted.php` was copied into `_scratch/harness/` before that tree's runs (r47 and r48 have no driver of their own; the recorded carried-over R4.6 driver was used). `_scratch_pre/` is the same copy with `Div.php` (parse and render) replaced by the preserved `.before-refcorr2.php` files; it was used only for the attribution control. All PHP runs were serial, through the tree's own harness on this machine (PHP 8.5.4), with empty stderr and exact case counts.

Rule lists. `RULES_FULL` is the 68-name full pipeline from `conformance-capstone/run_oracle.py` (also `pipelineFull` in `lean-ftml/LeanFtml/Pipeline.lean`). The R4.2 family-prefix runs use its first 54 names (ending at Paragraph, per REPORT-R42.md section 3); the R4.1/R3.6 notes-prefix runs use the 23 names Prefilter..Bibcite (REPORT-R4.md section 3). The CAPSTONE restricted runs drop the leading `Include,`.

Per-tree regenerated artifacts are under `conformance-stale-audit/<tree>/` with `-states.jsonl` / `-renders.jsonl` suffixes; the control outputs carry a `-pre` suffix. Scripts: `regenerate.sh` (all stage runs), `analyze.py` (byte/canonical classification), the inline Python drivers recorded in this directory's analysis files (capstone spots and refphp spots). Nothing under any `conformance-*` tree, `ref-php/`, or `lean-ftml/` was modified.

Control. The r46 family regeneration reproduces the retained `conformance-r46/family-states-full.jsonl` and `family-renders-full.jsonl` byte-for-byte (1,967 cases), exactly the control recorded in REPORT-ADOPT-CORR.md section 4. The same procedure reproduces the retained r42 notes-prefix artifacts byte-for-byte with the 23-rule list, and the retained r42 family-prefix/full, r45 prose740 and r47 prose740 artifacts byte-for-byte when Div.php is reverted to `.before-refcorr2.php`.

Comparison protocol. Raw byte equality is the CURRENT test. For a differing artifact, states are compared with `conformance-capstone/compare.py:canon_state` (per-document token-table renumbering, Collapsible/Tabview counter canonicalization, placeholder rewrites inside byte-wire option values); renders are compared after rewriting `\xFF<digits>\xFF` spans with the owning document's renumber map. Pre-CAPSTONE spot states use `include_doc_inc=False`, matching the archive-compatibility rule documented in `compare.py`'s header, because those records predate the disclosed driver extension that added `inclusions` and `inclusionsNotExist`. Movement that survives canonicalization is real; movement that does not is STALE-BENIGN.
