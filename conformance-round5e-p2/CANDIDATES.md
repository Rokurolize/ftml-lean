## C-R5E-P2-1 — U+200C ZERO WIDTH NON-JOINER lead before `_default:` (R5EP2-01)

Source `[[[\u200c_default:x]]]`, page `muse-probe-round5e-p2-r5ep2-01`. The live capture serves href `/x` with auto label `x`; ref.jsonl line 1 serves href `/_default:x` with the same label. The divergence is the rule-level slug after the standard mask, not the shared `class="newpage"` serving surface. The owning reference file is `ref-php/text-wiki/Text/Wiki/Parse/Default/Freelink.php` line 240: the REFCORR11 lead alternation is `E2 80 [\x80-\x8B\xA8\xA9\xAF]`, so the immediate byte successor E2 80 8C (U+200C) is not stripped, is transliterated to a separator, and leaves the `_default:` category in the slug. Live strips it. This is a fresh third-order sibling of the changed mechanism: REFCORR11 admitted E2 80 8B (U+200B) as the successor of U+200A but explicitly left U+200C unevidenced and excluded. Mirror consequence inferred by reading `lean-ftml/LeanFtml/LinkRules.lean` line 1044 (`0x2000 <= cp && cp <= 0x200B`) and the documenting comment at lines 1036-1037 (U+200C deliberately not admitted): the mirror transcribes the reference boundary and therefore also disagrees with live. ## C-R5E-P2-2 — U+2061 FUNCTION APPLICATION lead before `_default:` (R5EP2-02)

Source `[[[\u2061_default:x]]]`, page `muse-probe-round5e-p2-r5ep2-02`. The live capture serves href `/x`; ref.jsonl line 2 serves href `/_default:x`, a rule-level slug difference after the standard mask. The owning reference file is the same `Freelink.php` line 240: its REFCORR11 range is `\xE2\x81[\x9F\xA0]`, ending at E2 81 A0 (U+2060), so the immediate successor E2 81 A1 (U+2061) is not stripped on the reference side while live tolerates it.
