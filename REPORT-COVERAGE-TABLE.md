`TableClass` is an inductive enumeration of 62 branch classes. `tableAllClasses_length` proves the count and `tableAllClasses_nodup` proves the enumeration has no duplicates. `TableShape` is a disjoint sum of the family's decision contexts: the plain scanner hit, a plain row's content and span outcome, a cell-marker bit vector, a plain render token, the advanced-table validation outcome, an advanced cell's header and paragraph bits, the nested-table kind (including the quoted-head witness family), one attribute-filter context, one id-prefix context, and an advanced render token. `tableClassify` maps a shape to the list of classes that context enables. A plain row emits its content class together with exactly one span class. A plain or advanced render token emits its type class and then the tag, span and attribute classes that token's options turn on. The attribute filter, the id prefix, the marker cascade, the nest kind, the scanner and the advanced-table outcome are single-valued.

Completeness over that structure is proved. `tableAllClasses_mem` shows every constructor is declared. `table_classify_sound` shows any emitted class is declared. `table_classify_nonempty` shows every shape emits at least one class. `table_witness_classify` supplies a representable shape for each of the 62 classes. `table_classes_exhaustive` identifies the class set with the image of the classifier, and `table_classification_complete` bundles coverage and exhaustiveness. `tbl_attr_exclusive`, `tbl_id_exclusive`, `tbl_adv_out_exclusive`, `tbl_marker_exclusive`, `tbl_nest_exclusive` and `tbl_scan_exclusive` prove the single-valued cascades. `tbl_empty_row_discards_span` records that a content-free row discards its span accumulator. `tbl_no_row_dominates` records that zero rows fail the table before the residue and cell checks. `tbl_header_suppresses_align` and `tbl_format_not_on_cell_end` record the plain renderer's closed arms. `tbl_title_and_hidden_blocked` records that title and hidden share one drop. The partition lifts to real render tokens by `tblShapeOfRender`, `tblRenderClassOf` and `tblMemClass`, with `tbl_shapeOf_isSome`, `tbl_render_complete` and `tbl_render_sound` for `RenderRuleId.table` and `RenderRuleId.tableadv`.

The fuzz is seeded and within-class. `conformance-covtable/run_fuzz.py` generates one family of cases per class, six per class except the fourteen witness frames, which are all used, with an even frame also carrying a trailing note paragraph. Variation stays inside the class: the cell text, the span count, the alignment word, and harmless extra attributes. An independent reimplementation of the branch tests in `classify.py` and in `driver.php` annotates every case, and the two annotations agreed on all 760 cases. Parse classes are whole sources, executed by the reference transform and by `lean-ftml-conformance-r45 --e2e-r45`. Render classes are single tokens, executed by the reference `token()` and by the same binary's `state` mode. `taIdEmpty` is a direct call of the empty `isolateId` arm and is recorded as uncomparable, because `buildAttrs` drops an empty value before that arm. A comparable case passes when the reference class list matches the expectation, the Lean status is `ok`, and the rendered bytes are identical.

## Named remainders

R-1 (divergence, live and the reference agree): equal-rank attribute order. `buildAttrs` in `Tableadv.php` sorts with `uksort` by wikidot rank and, because PHP 8's sort is stable, keeps authored order inside a rank. Live does the same: `muse-probe-covtable-data-order` renders `<td data-z="1" data-a="2">`. `buildAttrsAdv` still finishes with `insertAttrB`, a name sort. `tbl_parse_insert_sorts_data_names` shows that inserting `data-a` beside `data-z` puts `data-a` first, and `rankAttrs` then keeps that order because both keys share rank 5. `tbl_data_before_colspan` shows the render repair across ranks: a stored `colspan` is moved after `data-name`. The six fuzz failures are exactly the three equal-rank sources on each seed. Lean rendered `data-a` before `data-z`; the reference rendered `data-z` before `data-a`. The `colspan` plus `class` sources in the same class matched, because those keys differ in rank and also happen to be alphabetical in the surviving order. This lane does not edit `TableRules.lean`. The divergence is classified as it stands and left for the owning correction lane.

R-2 (divergence, live is definitional): a whitespace-only `class`. `muse-probe-covtable-norm-drop` renders `<td class="">Blank</td>`. The reference `buildAttrs` drops `class`, `id`, `role`, `style` and `type` when the normalized value is empty, and the harness transform of the same source is `<td>Blank</td>` with an empty attribute list. The mirror agrees with the reference: the six `taAttrNormDrop` cases passed on both seeds. The class is the reference's drop arm. Live keeps the empty class attribute. The reference is not changed here to hide that difference.

R-3 (unreachable arms, designed direct pins): `taIdEmpty` is dead because `buildAttrs` drops an empty value before `isolateId`; `tbl_isolate_empty` records `isolateIdAdv [] = []`, and the six cases per seed are uncomparable. `tbRCaptionStart`, `tbRCaptionEnd`, `tbRRowspan` and `tbRFormat` are render arms the active plain-table parse never feeds. `tbRFall` and `taRFall` are the default arms for a type name the parse does not emit. Each is exercised by a direct `token()` call in the fuzz, and those calls matched the mirror.

R-4 (cited, not re-derived): the fourteen Tableadv witness frames. `tableadvWitnessFamily` already has length 14 and no duplicates, and `mirror_enum_witness_family` is the enumeration proof from TABLEADV-FIX. This lane's `taEnumQuoted` cases are those frames, half of them with a trailing note paragraph, and all 28 executions matched the reference. The search is not repeated here.

R-5 (within-class variation): `hidden` shares the `title` drop. `adv34-title-attr` pins `title`. The fuzz varies `hidden` inside `taAttrBlocked`, and those cases matched. `role` and `type` are the same rank sort as `class` and `style`; `adv23-colspan-bad` and `adv35-many-attrs` pin the sort, and `tbl_rank_slots` records the seven numeric ranks as one theorem rather than seven classes.

## Closing accounting

The family's input classification is proved. On `RenderRuleId.table` and `RenderRuleId.tableadv`, `tblRenderClassOf` is total and `tblMemClass` is that function read on a real render token. The attribute, id, marker, nest, scan and advanced-outcome cascades are exclusive, and a plain row's span class is exclusive with its content class. Every one of the 62 classes has a live probe, a retained battery pin, or a recorded reason with a designed direct-call pin for an arm a page cannot enter. The seeded within-class fuzz agrees with the reference on 742 of 748 comparable cases across two seeds. The 6 disagreements are the equal-rank attribute order of R-1. The 12 uncomparable cases are the dead `isolateId` arm of R-3. Live Wikidot behavior stays definitional: R-2 records that a whitespace-only class is kept live and dropped by the reference, and the reference is not edited to hide it.
