# Pre-probe ledger addendum — SUSPECT4-B follow-up batch F2 (written before any muse-probe-suspect4b-f2-* page was created)

This addendum refines the one rule-level differential the first batch produced after campaign-standard masking (S4B-08, the leading-space _default: slug) and probes four further source-span edges named in BRIEF-SUSPECT4-B that the first batch's shapes did not reach. The same framing holds: P_code is the exact tree-harness byte string in ref-render-f2.jsonl (php ref-php/harness/batch.php render, zero stderr), P_confirm is the live byte that would uphold the suspicion, P_clear the live byte that would clear it. Campaign-standard masking (wikidot-probe norm, applied symmetrically in compare_s4b.py) deliberately drops class="newpage", sorts tag attributes, decodes numeric entities, masks time_N and drops scripts; differences that survive it are rule-level, differences it removes are serving/frame surfaces and are CLEARED.

S4B-27 (f2-def-bare, f2-def-space-label, f2-def-tab, f2-def-2space, f2-def-space-cafe, f2-def-space-upper) — the reference strips a leading _default: only when the regex ^_default: matches the untrimmed raw target, so a leading space, tab or doubled space keeps the category in the slug, and a non-ASCII suffix keeps it too. Suspicion: live strips the category after its leading whitespace is trimmed, so every one of those slugs loses _default:. P_code hrefs are /x for the plain bare control, /_default:x for the space, tab and two-space forms with and without a label, /_default:cafe for the Café form and /_default:x for the uppercase prefix form. P_confirm: the leading-whitespace forms serve /x or /cafe while the bare control also serves /x. P_clear: the leading-whitespace forms keep /_default: as P_code says. Reachable: a wiki link pasted with a stray leading space inside the brackets.

S4B-28 (f2-def-mid, f2-def-colon-space, f2-colon-bare) — a category prefix that is not at the very start (x _default:y) or is generic rather than _default: (foo:bar) must stay in the slug under the reference's anchored strip; the leading-space generic form keeps the whole slug but strips the display text at the first colon. Suspicion: live applies a general category-prefix strip to the slug for any colon form, which would make the whole class of colon slugs diverge. P_code hrefs are /x-default:y, /foo:bar and /foo:bar with display texts y, bar, bar. P_confirm: any of the three hrefs losing the prefix. P_clear: all three byte-identical to P_code. Reachable: ordinary category-qualified page names.

S4B-29 (f2-math-url-dollar) — REFCORR6 added a narrow guard yielding a described Url match whose text contains the math closer's `$]` fragment. Suspicion: live does not yield and the math body is claimed by Url, changing the span. P_code is `<span class="math-inline">$[http://example.com $]$</span>` — the whole authored body preserved. P_confirm: a link span or a truncated math body. P_clear: byte-identical to P_code. Adversarial-only.

S4B-30 (f2-math-code-span) — a Code token whose closer sits across the math closer is the edge where the claimed source might swallow `$]]`; the reference trims the math match at Code's opener and leaves the code closer literal outside. Suspicion: live preserves the whole code source or suppresses the formula. P_code is `<span class="math-inline">$[[code]]x$</span> y[[/code]] B`. P_confirm: any different body. P_clear: byte-identical to P_code. Adversarial-only.

S4B-31 (f2-math-two-urls) — two described Url tokens in one math body test whether the per-token source side table keeps both authored spans in order. Suspicion: one span is lost or duplicated. P_code is `<span class="math-inline">$[http://a.com x] [http://b.com y]$</span>`. P_confirm: any different body. P_clear: byte-identical to P_code. Adversarial-only.

S4B-32 (f2-math-free-in-email) — a Freelink suppression-set member inside a described Email's claimed source, one level shallower than the Url-nested control in the first batch. Suspicion: live fails to suppress at this nesting. P_code is `<span class="math-inline">$$</span>`. P_confirm: any non-empty body. P_clear: `$$`. Adversarial-only.

S4B-33 (f2-fl-emoji, f2-fl-digit-space) — an unmapped supplementary-plane character beside ASCII letters, and a leading digit after a leading space, are the transliteration edges past the first batch's BMP © and unspaced digits. Suspicion: live maps the emoji differently or drops the leading space's effect. P_code hrefs are /cafe-x (emoji is an unmapped separator, both ASCII letters kept) and /123abc (leading space trimmed, digits kept). P_confirm: any different href. P_clear: byte-identical to P_code. Reachable: emoji in page names and stray leading spaces.
