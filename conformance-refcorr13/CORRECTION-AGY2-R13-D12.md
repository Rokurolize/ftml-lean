# CORRECTION-AGY2-R13-D12 — WDStringUtils transliteration: Ł, ś and the duplicate Ä (R13-AGY2, 2026-11-23)

This is a mechanism-unit draft for the coordinator to place at conformance-refphp/next/user/CORRECTION-AGY2-R13-D12.md after adoption; it changes no canonical file itself. It responds to hunt confirmation D12, which indicted `ref-php/wikidot-root/lib/WDStringUtils.php` lines 30, 44 and 84 through `Render/Xhtml/User.php:45`. All witnesses are frozen agy-hunt captures plus the fossil file itself; no new live probe was fetched.

Three minimal edits to `$CONVERT_ARRAY`. First, line 44 has `'Ł'=>'K'` instead of `'Ł'=>'L'`; since `toUnixName()` lowercases AFTER `strtr`, the fossil produced `kukasz` for `Łukasz`, while the live capture `muse-probe-agy-hunt-m15a-user-lukasz` resolves the user `lukasz` (id 45707), proving `Ł -> l`. The patch changes only the `Ł` value to `L`; the other K-mapped letters (`Ľ`, `Ĺ`, `Ļ`, `Ŀ`) are left alone because no witness implicates them. Second, lowercase `'ś'=>'s'` is missing beside `'š'=>'s'` at line 84, so ` ślimak` slugified to `limak`; live capture `m15b-user-slimak` resolves `slimak` (id 318027). The patch adds `'ś'=>'s'`. Third, line 30 contains duplicate keys `'Ä'=>'Ae','Ä'=>'A'`, and PHP array-literal last-key-wins collapses them to `Ä -> A`, so `Äpfel` became `apfel` while `äpfel` became `aepfel`. The patch removes the conflicting `A` entry, leaving one `'Ä'=>'Ae'`, restoring upper/lower symmetry. Verified firsthand by calling the patched `WDStringUtils::toUnixName` directly: `Łukasz => lukasz`, `ślimak => slimak`, `Äpfel => aepfel`, `äpfel => aepfel`. Before the patch the same calls returned `kukasz`, `limak` and `apfel`.

Caveat stated plainly: the hunt report measured live only for `Ł` and `ś`; there is no frozen live `Äpfel` capture in any conformance directory. The `Ä` change is derived from the fossil's own duplicate-key collapse and the measured lowercase `ä -> ae` symmetry, not from a new probe. If the coordinator wants a live `Ä` witness before adoption, that must be a separate probe round; this unit cannot fetch one.
