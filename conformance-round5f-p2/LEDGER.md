## Mechanism summary for the changed families

REFCORR12-FREELINK replaced the REFCORR10/11 enumerated and byte-successor lead lists in Freelink.php line 213 with one no-/u byte-oriented alternation `isLead(cp) = isUnicodeFormatCp(cp) || isUnicodeWhiteSpaceCp(cp) || cp == 0xFEFF || cp == 0x2A`, cp != 0, pinned to the full Unicode 17.0 Cf set plus the White_Space property. The five round-5e confirmations (U+200C, U+200D, U+2061, U+2064, mixed U+200B+U+200C) merely forced the generalization; the other 191 union members and the immediate excluded neighbours were never measured. The PHP stays byte-oriented (no /u) so a malformed tail cannot switch the strip off. REFCORR12-GENERAL introduced a rule-local right-trim of technical attribute values in Div/Span/Image at the consumer, while text/label values are kept verbatim and Math::process still passes its `type` value straight from getAttrs to the render validator `^[a-z][a-z0-9]*$`; getAttrs itself does not trim values. REFCORR11-MATH retired the REFCORR3 absent-type `align` default in favour of `array_key_exists('type', $args) ? $args['type'] : 'equation'` at Math.php line 102, so only an exact lower-case `type` key selects a non-equation environment and its value flows verbatim to the renderer. The mirror consequences are inferred by reading lean-ftml/LeanFtml/LinkRules.lean and NextRules.lean only; no Lean elaboration was run and no mirror file was edited.
