The minimal pre-rebuild symptom is recorded for the coordinator as build history, not as a divergence witness: `nestedCases` index 0, source bytes `[[module a]]\n[[module a]][[/module]]\n[[/module]]` (48 bytes), actual replacement `[[module654 a]]\n[[module a]][[/module]]` (37 bytes), expected `[[module654 a]]\n[[module a]]\n[[/module]]` (38 bytes), one `0x0A` LF missing after the inner opener; all 32 inline cases failed identically and all 32 line cases passed. After `lake build LeanFtml` through `lean-build.sh` (exit 0), `ModuleProof.lean` elaborates at exit 0 with all 27 theorems and zero `sorryAx`. No mirror source, `Main.lean` or reference file was edited, and no genuine mirror/reference divergence was found, so no correction-round witness is opened by this lane.

## New work by unit

The work was divided on the shared team board into one unit per theorem group with disjoint proof-file write scopes; the root integrated, ran the gates and owns the commit. Every unit elaborated its own file through the wrapper at exit 0.

### module_parse_env_independent — `ModuleEnvProof.lean`

This closes the policy's key parse boundary theorem in the strongest form this branch can type. There is no `RenderEnv` or `ProofInterface` here, so `ModuleNameEnv` carries exactly the data the harness registry holds (a list of available name byte lists) and wrapper functions thread it through `modulepreRule`, `moduleRule` and `module654Rule` and through the whole scanner closure `modulepreScan`, `moduleScanPass`, `modulePasses` and `module654Scan`. The mirror's actual signatures take no environment, so each wrapper is definitionally its mirror function and environment erasure is `rfl`. `module_parse_env_independent` is universal over any two environments and any `ParseState` for all three rules; `module_parse_env_independent_components` names the equal work, byteForm-of-work and token tables explicitly; `module_parse_closure_env_independent` does the same at scanner level; `module_harness_vs_other_names_witness` contrasts the harness nine-name list with a disjoint three-name list on a source that claims one Module token, so the witness is not vacuous. Ten theorems, all audited with `#print axioms`.

### renderModule handoff contract — `ModuleHandoffProof.lean`

`ModuleHandoffEnv` is the minimal interface-free carrier with one field `moduleAvailable : List Nat → Bool`; `harnessHandoffEnv` is the projection matching `moduleAvailableNames` in `ServingRules.lean`. `renderModuleWithEnv_harness` proves the wrapper is byte-identical to the mirror for every `OptMap`. `renderModuleWithEnv_available`, `renderModuleWithEnv_available_marker` and `renderModuleWithEnv_unavailable` prove the two exact branches parametric in any environment: the `\xFE module "Name" <urlencoded attr> \xFE` marker and the `"No such module"` error block. `moduleErrorBlock_eq` and `moduleErrorTemplate_no_rel` pin the error template and prove the fixed prefix and suffix contain no `rel` bytes. `quotedName_append_injective` and `moduleHandoffMarker_injective_on_fenced` prove name injectivity of the marker under `NameFenced` (name bytes contain no `"` byte 34), which is the honest byte-level scope of that claim. Eight theorems, all audited.

### Closer-spelling converse — `ModuleCloserCompletenessProof.lean`

This closes the inherited report's first named remainder. The unit proved both the requested bounded certificate and, because the mirror's matcher admits a genuine induction, a universal Lean theorem: `cert_mem_ciMatches` gives `matchLitCI pat c = some [] ↔ c ∈ ciMatches pat` for arbitrary pattern and byte list, and `cert_universal` specializes it to the mirror's closer literal and its 64 case spellings. The bounded certificate is still recorded honestly: generator `certSpellings` (the 2^6 case product) plus 640 near misses over ten classes (wrong brackets, injective wrong letters, truncations, extensions) for a 704-element duplicate-free domain, cardinality theorems, zero-mismatch `decide` check and deterministic hash `555987450`. The universal theorem is about the Lean mirror's byte matcher only; it makes no Boundary-B claim about PCRE2 `/i` semantics and says nothing about placeholders or closer parsing inside arbitrary sources. Nineteen theorems, all audited.

### Authored-closer carry certificate — `ModuleCloserCarryProof.lean`

This addresses the inherited report's second named remainder with a mix of universal list arithmetic and a bounded semantic certificate. Universally proved: `carry_drop`/`drop_last11` (the last eleven bytes of `matched` are the closer whenever the source decomposes as `pre ++ closer ++ tail`), `take_append_rest_eq_iff_suffix` and `close2Suffixes_suffix`/`suffix_drop_two` (suffix criterion and structural suffixness of attribute candidates). The semantic link is certified over `genFrames`, a generated family of 1536 frames from two name shapes, three attribute groups, two Code-placeholder body shapes, all 64 closer spellings and two tails; `carryOk_all` is a kernel `decide` and `generated_carry` lifts it to each generated frame, stating that the emitted last eleven bytes equal the authored closer and the closer `findSubCI` located. Generator, cardinality 1536 and deterministic hash `412587544` are recorded in the file. The arbitrary-source implication remains open and is named below. Eighteen theorems, all audited.

### Defense over all 64 closers — `ModuleDefenseDomainProof.lean`

This addresses the inherited report's third named remainder by widening the closer dimension from the two spellings in the inherited 32-case product to all 64. `ddCases` is a 512-case product of two outer names, two inner names, two bodies and 64 closers, checked in both inline and line shapes for 1024 kernel `decide` cases; `ddInlineDefense_all`, `ddLineDefense_all` and `ddDefenseDomain_all` pin the exact replacement shape, the single inserted LF after an inline inner opener, the absence of one after a line-terminated opener, the outer-closer residual and the empty token table. Generator and cardinality (64 closers, 512 cases, 103936 domain bytes) and deterministic FNV-style hash `2400177605` are recorded. The file sets `maxRecDepth 200000` for the large product; a first attempt at default depth produced a synthetic `sorryAx` and was discarded rather than committed. Eight theorems, all audited.

### Universal REFCORR10-MODFIX helper lemmas — `ModuleDefenseLemmas.lean`

All declarations sit in sub-namespace `LeanFtml.ModuleDefenseLemmas`. These are universal theorems about the mirror's own inline-newline helpers, with no ground `decide`: `spacesThenNewline_eq_true_iff` exactly characterizes spaces-then-LF; `moduleHeadEnd_eq_some_spec` proves head soundness (length bounds, the `]]` suffix, the tail decomposition); `go_step_line_terminated`, `go_step_inline_inserts_lf` and `go_step_shape` prove that one step inserts LF exactly when the detected head's tail is not spaces-then-LF; `go_fuel_irrelevant` and `insertInlineOpenerNewlines_fuel_sufficient` prove extra fuel never changes a pass. ### modulePasses termination/fixpoint — `ModuleTerminationProof.lean`

This is the lane's primary named remainder. The mirror's `modulePasses` is structurally total, but reaching a *fixpoint* needed a real argument. Proved universally: `moduleScanPass_fuel_sufficient` and `moduleScanPass_extra_fuel` (the scan's `src.length + 1` fuel is never exhausted, through `moduleMatch_rest_shorter`), `countModuleOpeners_mul_le_length` and `moduleMeasure_le_length` (the policy's line-start plus inline opener measure is at most the source length, twelve bytes per opener), `modulePasses_eq_of_pass_eq` (an unchanged pass stops immediately), and the conditional theorems `modulePasses_reaches_fixpoint_of_measure` and `module_fixpoint_terminates_of_measure_decrease`: given the step law `moduleMeasureStepOK`, `modulePasses (src.length + 1)` reaches a byte-stable fixpoint. The step law itself is **not** claimed universally. Instead a bounded kernel-`decide` certificate closes it over 259 generated sources from a six-token alphabet (`[[module a]]`, `[[module654 a]]`, both closer spellings, LF, `X`) up to three tokens, with cardinality 259 and FNV-1a/32 hash `53997995`; `module_fixpoint_terminates_certified` lifts it to each family member. Thirty-one theorems, all audited. The gap is stated exactly below.

### Search-helper first-occurrence laws — `ModuleFindSubProof.lean`

This closes the minimality gap left open by the universal defense-helper unit. In sub-namespace `LeanFtml.ModuleFindSubProof` it proves universally that `findSub` returns the first case-sensitive occurrence (prefix at the hit, exact take decomposition, minimality, no earlier hit, empty-pattern case) and that `findSubCI` returns the first case-insensitive occurrence under `matchLitCI` (hit decomposition with the actually consumed bytes, minimality, no earlier hit, empty case). ### Token-table growth invariant — `ModuleTokenTableProof.lean`

In sub-namespace `LeanFtml.ModuleTokenTableProof`, the `TokensExtendBy k` predicate captures extension of a token table by at most `k` appended entries. Proved universally: `claimModule` appends exactly one token with `phBytes toks.length`, the defense branch leaves the table unchanged, every `moduleTryCands`/`module654TryCands`/`moduleMatch`/`module654Match` result extends by at most one, and `moduleScanPass`, `module654Scan` and `modulePasses` extend the input by induction on fuel; `modulePasses_step_length` gives a per-pass bound. The exact claim count in a scan is not characterized and an aggregate bound depending only on pass fuel is not true without bounding intermediate source growth; both are named. Nineteen theorems, all audited.

### Module654 tail and C1 contrast — `Module654TailProof.lean`

### Trim and claim-option laws — `ModuleTrimProof.lean`

In sub-namespace `LeanFtml.ModuleTrimProof`, nineteen universal theorems characterize PHP trim's six-byte set, prove `trimBytes` idempotence and the exact fixed-point condition, give a decomposition `bs = pre ++ mid ++ suf` with trim-only ends and untrimmed middle, and prove `List.Sublist (trimBytes bs) bs`. `claimModule`'s own contract is pinned (placeholder index equals input token count, exactly one token appended with the three module options), and `claimModule_trims_are_recorded` records the trimmed attr/body at the mirror's claim sites. No UTF-8 validity claim, and no proof that any particular source reaches the claim branch; those are matcher concerns.

### Measure-decrease attempt — `ModuleMeasureStepProof.lean` (negative result)

A dedicated unit attempted the universal step law that would make the fixpoint theorem unconditional. It proved a genuine universal one-match partial law (`one_match_measure_strict_decrease` under a no-defense, no-Code-gate-reemit, opener-free-residual hypothesis) and a trivial byte-and-token-unchanged stability lemma, but it also **refuted** the measure-decrease law that the policy suggests as the pass measure. `step_counterexample` is kernel-checked: for `src = [[module a]]\nX[[/module]][[module b]]` with an empty token table, one `moduleScanPass` changes the bytes and `moduleMeasure src = 1 < 2 = moduleMeasure out`. The claim's trailing `\n\n` turns a residual opener that had followed a closer into a line-start opener, and the recomputed line-start/inline count grows; `not_universal_measure_step` states the negated universal law. This is a substantive finding: the conditional fixpoint theorem plus bounded certificate is the honest maximum for this measure, and an unconditional theorem needs a different measure or a whole-rewrite-sequence amortisation invariant. It is recorded here as a minimal witness; no mirror file was changed. Nineteen theorems, all audited.

### Byte-stable implies token-stable attempt — `ModulePassTokenStabilityProof.lean`

The unit proved that a claim changes the head byte of its matched text (LF `10` versus opener byte `91`), that a claim reached through a path of copied bytes therefore changes the output, and that any token-table change is exactly one appended `TokenEntry`. It then gives whole-pass conditional forms under explicit `ReachesClaim` and `ScanNoClaim` path hypotheses. The unconditional law `out = src → t = toks` is **not** asserted: an earlier defense rewrite can insert `654` and LF bytes, shifting the output relative to the input so that a later claim's head-byte argument no longer holds; with arbitrary byte sources, shifted bytes can coincide and lengths can compensate. Ruling that out needs the same whole-rewrite-sequence invariant named above. Fourteen theorems, all audited.

Fifteen theorems were audited; no full scanner induction is claimed.

### Defense rewrite case-sensitivity — `ModuleDefenseRewriteProof.lean`

The composition's no-new-head claim is conditional on the newline-insertion output, stated explicitly. The defense count hypothesis is not connected to PCRE's `preg_match_all` here. All nine theorems were audited.

## Remainders and rebase risk

The interface remainders are exact. This branch has no `RenderEnv`, `harnessEnv`, `ProofInterface`, `RuleProofBundle` or `RenderProofBundle`: F1/F3 of the foundation sprint have not landed. `module_parse_env_independent` is therefore proved over `ModuleNameEnv` with a name-list field and `renderModule_handoff_iff` over `ModuleHandoffEnv.moduleAvailable`; when F3 lands those carriers must be replaced by `RenderEnv.moduleAvailable : List Nat → Bool` and the pointwise hypothesis `∀ n, env₁.moduleAvailable n = env₂.moduleAvailable n`. The parse-side mirror functions take no environment argument and need no change; the handoff wrapper reads exactly the field that F3 will provide. Everything downstream of decoding the `\xFE module ... \xFE` marker — name resolution, module execution and body evaluation — is deepwell's domain and is formally fenced outside LeanFtml.

The termination remainder is exact and is stronger than an unproved gap: the policy's proposed strict-decrease measure is false, with the kernel-checked witness `[[module a]]\nX[[/module]][[module b]]` (measure 1 before a pass, 2 after). What stands is the universal conditional fixpoint theorem, the universal scan-fuel and measure bounds, a 259-source bounded certificate with recorded generator and hash, and the explicit statement that an unconditional theorem needs either a different measure or a whole-rewrite-sequence amortisation invariant, and that byte-stability is not yet full-state stability. The closer-carry and defense certificates are bounded as recorded (1536 frames, 512 × 2 cases), with arbitrary source provenance, arbitrary names and bodies, arbitrary tails, mixed-case openers and other attribute shapes named outside their domains. None of these results equates the mirror to PHP 8.5, `libpcre2` or `libtidy`; Boundary A and Boundary B conformance remain the coordinator's separate gates, and module evaluation stays out of scope programme-wide.

Rebase risk is concrete. The module mirror was last changed by the REFCORR10-MODFIX adoption (`c5840c6`); the in-flight REFCORR12 and the planned F2 `PcreCore` refactor can change `ModuleRules.lean` and `ServingRules.lean`. Any such correction round forces a rebase of these proof files and a re-run of the whole gate; the stale-olean incident at the start of this lane is the exact failure mode a rebase must avoid, so the coordinator should build the library from the rebased source before trusting any axiom line. All theorem statements are about this branch's mirror functions, and the proofs are intentionally mirror-internal so they survive only as long as those functions do. Import wiring is the coordinator's adoption action; this lane did not edit `LeanFtml.lean`, `Main.lean`, the lakefile or any mirror source. The tracked `.lake/build` tree was refreshed locally for trustworthy evaluation and its 245 modified artifacts are deliberately excluded from the commit.
