# CORRECTION-C-R5E-P3-2 — right-trim trailing whitespace of the Image `class` attribute (round 5e)

Evidence. Candidate `C-R5E-P3-2` was confirmed on a valid, stable, saved-source-matching live capture `muse-probe-round5e-p3-p3e-09-img-class-trailing` (html_sha256 `64e5779bc2c156779d28131c8341822a059d94a64667ab2f079d9ad199abbe2b`): source `[[image IMG.png class="thumb "]]` serves `<img src="https://sandbox-for-codex.wdfiles.com/local--files/muse-probe-round5e-p3-p3e-09-img-class-trailing/IMG.png" class="thumb" alt="IMG.png" />` while the canonical reference at `ref.jsonl` line 9 emits `<img src="/local--files//IMG.png" class="thumb " alt="IMG.png" />`. The decisive rule-level byte is the `class` attribute value: live `class="thumb"` against reference `class="thumb "`. Both sides omit the automatic `image` class because an authored class overrides it, so the only surviving difference is the trailing space. The wdfiles host and page path on `src` are the owned serving surface, masked in `comparison.json`.

Mechanism. `ref-php/text-wiki/Text/Wiki/Parse/Default/Image.php:153-154` copies the authored `class` into the option map unchanged, and the REFCORR11 rtrim at `Image.php:216-219` is link-only, so the trailing byte of `class` reaches the renderer. `Render/Xhtml/Image.php:207-219` emits the class value verbatim after `htmlspecialchars`, and the class branch at `Image.php:213-214` sets the automatic CSS class to null, giving the observed `<img class="thumb " ... />`. The fix is to right-trim the `class` value over the rule's own ctype_space / PCRE `\s` byte set at the same consumer point as the link trim, applying it to `class` in addition to `link` and `width`, without touching the whitelist order, the automatic-class override, the alignment, source-star handling, target or escaping. P3E-06 and P3E-07 show `title` and `alt` must remain untrimmed.

Mirror consequence. `lean-ftml/LeanFtml/ParaRules.lean:294-300` carries `class` verbatim into `attr2` and the REFCORR11 twin at `ParaRules.lean:321-322` trims only `link`; `ServingRules.lean:411-420 imageAttrEmit` emits the class value through `htmlSpecialCharsCompat` and `ServingRules.lean` clears the automatic class when an authored class is present. The mirror is therefore inferred by source reading to emit `class="thumb "` and to carry the same divergence; no Lean elaboration was run in this evidence-only unit.

Scope. No canonical file, ftml file or source file was edited by this unit; no cargo, git identity override or git stash was used. Canonical adoption, the mirror patch and gate regeneration remain coordinator actions outside this unit's write set.
