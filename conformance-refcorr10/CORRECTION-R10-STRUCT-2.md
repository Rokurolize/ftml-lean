# CORRECTION-R10-STRUCT-2 — general nested-unknown-module body consumption

Family 2 general rule: consumption through trailing closers applies to every nested module opener in a module claim, not only to an inner opener whose own tail already ends in a newline. For a claim with n authored openers, the outer module token owns the whole nested span and n authored closers are consumed, one per opener; no residual literal `[[/module]]` survives. The outer module result (for an unknown name, the error block alone) is the only emitted output, while REFCORR7 Raw suppression, REFCORR8 Code-only narrowing, REFCORR9 authored-closer carry and the `moduleTail` pair return type are preserved unchanged.
