# CORRECTION-R10-STRUCT-1 — general Tableadv data-* attribute key grammar

Family 1 general rule: after the exact lower-case `data-` prefix and the REFCORR8 fold to lower case, the live-observed data-* suffix key class is `[a-z0-9._-]` — ASCII lower-case letters (bytes 97..122), digits (48..57), underscore (95), hyphen (45) and dot (46) — with the same `*` quantifier as the settled gate, so an empty, leading, trailing or repeated separator is admitted. The non-data block-head grammar `^[a-z][a-z0-9-]*$` (Lean `advKeyOk`) is NOT widened, and the recognised data prefix stays the exact lower-case `data-`, so an upper-case `DATA-` prefix, `aria-*`, `align` and every other non-data key keep their settled drop behavior.

Derivation from cached key shapes only, no new live probe: the REFCORR9 gate `preg_match('/^data-[a-z0-9_-]*$/', $key)` admitted lower-case letters, digits, underscore and hyphen. The `*` quantifier is retained from the settled gate because no cached case distinguishes an empty or edge-positioned suffix from a middle one.
