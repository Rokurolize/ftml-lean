# CORRECTION-C-R5B-P3-2 — Tableadv data-* key with an underscore

Candidate `C-R5B-P3-2`, family Tableadv, confirmed by unit R5B-P3 on post-REFCORR8 ground (canonical commit `b909f33`). Minimal source `[[table data-Foo_Bar="UB"]]` with one row and one cell (case `p3b-07-tableadv-data-underscore`, page `muse-probe-round5b-p3-p3b-07-tableadv-data-underscore`). The capture is valid, stable and saved-source-matching; decisive live bytes are `<table data-foo_bar="UB">\n<tr>\n<td>CELLX</td>\n</tr>\n</table>` at html_sha256 `97e0c65f8d32a5991ce5d2be851630242f0054f319f9f499437260baec56595b` and source_sha256 `3e9813c787b4eddfc5028d8c9d8d89a088f2f797c29eeece3814f220643fdda0`. The canonical reference render is `<table>\n<tr>\n<td>CELLX</td>\n</tr>\n</table>` (`ref-render.jsonl` row 7). The live table carries the folded `data-foo_bar` attribute while the reference drops it. This is a rule-level attribute presence and key value, not a serving surface.

Owning reference file is `ref-php/text-wiki/Text/Wiki/Parse/Default/Tableadv.php`. REFCORR8 C-R5-P3-2 added `if (strpos($key, 'data-') === 0) { $key = strtolower($key); }` at lines 154-156, then still applies the block-head gate `/^[a-z][a-z0-9-]*$/` at line 157; the underscore in `data-foo_bar` fails that gate and the attribute is dropped. The sibling cases in this unit fix the boundary: a row-head `data-Foo` folds to `data-foo` on live (cleared), an uppercase `DATA-Foo` prefix is dropped (cleared), and an uppercase `Class` is dropped (cleared), so only the data-* key grammar after the fold is wrong. The mirror transcribes the same mechanism: `lean-ftml/LeanFtml/TableRules.lean` lines 375-413 define `foldDataKeyAdv` then `advAttrStep` with `if !advKeyOk k then acc`, and `advKeyOk` at lines 368-373 admits only lowercase letters, digits and `-`, so `data-foo_bar` is dropped there too. Source reading therefore infers the same mirror divergence; no Lean elaboration was run by this hunt unit. A fix owner must keep `advKeyOk` unchanged for non-data keys (the CoverageTable key-shape pin depends on it) and relax only the data-* key grammar to match live, without reviving aria-* or align, which remain dropped.
