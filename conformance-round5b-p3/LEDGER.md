# LEDGER — R5B-P3 parse-side structural rules, written before any live probe

Ground is post-REFCORR8 canonical commit `b909f33` (build green per R8-FIX); canonical base before REFCORR8 was `e53e7234008860a92e53b93d851c49a0e2b04043`. Every row below was raised by fresh reading of the corrected reference PHP in `ref-php/text-wiki/Text/Wiki/Parse/Default/` and the paired Xhtml renderers, before any live capture. Live Wikidot is definitional however malformed. The standard mask is `probe.norm` plus the campaign frame rule: inter-tag and trailing-paragraph newlines, `&nbsp;` spelling, random element ids, date attributes, token-id counter digits and Stage 2 purifyHtml frame are owned classes, never divergences. Serving-layer surfaces (wdfiles hosts, gallery lightbox script, module placeholders, `class="newpage"`) are CLEARED, never confirmed. Rows P3B-01 to P3B-04 are siblings of the REFCORR8 Raw 4+3 closer fix at `Raw.php:151-155`; rows P3B-05 to P3B-08 are siblings of the REFCORR8 Tableadv uppercase data-* fix at `Tableadv.php:150-156`. No round-5 shape is re-probed here: every row is a different construct or a different branch of the corrected mechanism. Include targets are created first under this unit's own prefix and recorded in `target-map.json`, following SUSPECT4-C.
