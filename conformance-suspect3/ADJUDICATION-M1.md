# M1 adjudication — C-SUSPECT-XRULE-5, the Mathinline placeholder battery (2026-11-22)

The dedicated battery the SUSPECT-XRULE lane said was missing was built and run before any correction attempt. Sixteen sources are in cases-m1.jsonl, the two observable predictions per source were written in LEDGER-M1.md before probing, the local reference renders are in ref-m1.json, and all sixteen live captures in captures-m1.json are valid=true, stable=true and saved_source_matches=true (capture-m1-retry.log; the first capture attempt aborted on a transient HTTP 408 and wrote no file, so the retry is the record). Pages live on sandbox-for-codex under the permanent prefix muse-probe-suspect3-m1-.

The live rule is now settled by the battery, and it is broader than the X24 observation. Mathinline preserves the trimmed authored body verbatim, with each earlier-rule placeholder effectively expanded back to the token's original source text, recursively; it suppresses the whole formula to `$$` when a placeholder from a Freelink, Raw, Newline or Image token occurs anywhere in the body, at any nesting level. Plain text, bare and described URLs, bare and described emails, and a Code block body are preserved verbatim including their own markup. The reference instead resolves exactly one level through token option values, drops the email address and brackets of a described email, leaks the inner placeholder as a visible replacement-digit-replacement, and only suppresses a Newline or Raw token at the first level.

Verdict by case, with frame-level shaping only (CRLF to LF, br spelling, newline-run collapse, outer-newline strip): m1-plain, m1-url, m1-email-bare, m1-raw, m1-newline and m1-two-urls MATCH byte for byte. m1-email-descr: reference `$Label$`, live `$[a@example.com Label]$` (DIVERGENCE, one-level option substitution). m1-freelink: reference `$Some Page$`, live `$$` (DIVERGENCE, Freelink suppression absent in the reference). m1-code: reference a malformed `A [[$ [[code]]x[<a href="/code]]">$</a>] B`, live `$[[code]]x[[/code]]$` (DIVERGENCE, the code closer's `]]` ends the reference math body early; live captures the whole authored body). m1-nested-email-url: reference `$\xFF2\xFF$` visible as a replacement-digit-replacement, live `$[a@example.com http://example.com/a]$` (the original X24 divergence, confirmed). m1-nested-email-free, m1-nested-email-raw and m1-nested-email-newline: reference a leaked index or the surrounding raw bytes, live `$$` in all three (DIVERGENCE, second-level suppression absent in the reference). m1-freelink-url: reference `$http://example.com/a$`, live `$$` (DIVERGENCE, Freelink suppresses even when its target carries a Url token). m1-image: both sides emit `$$`; live omits the paragraph wrapper because the image token claims the line, a frame/serving surface already owned elsewhere, not a Mathinline divergence. m1-email-descr-url-first: reference `$a@example.com$`, live `$[http://example.com/a a@example.com]$` (DIVERGENCE, same one-level substitution defect with the roles reversed).

Adjudication of C-SUSPECT-XRULE-5: CONFIRMED DIVERGENCE, closed here as candidate C-SUSPECT3-1, with no local reference edit. The reason is now evidence-backed rather than a claim of insufficient data. The reference's token table stores only a rule name and an options array (Text/Wiki.php addToken, lines 1275-1304); it does not retain the original matched source text. Live's behavior is a raw-body-preservation rule that depends on source text earlier rules have already replaced. Reproducing it locally would require either a pre-tokenization capture pass over `[[$ ... $]]` bodies (a pipeline-order change touching all sixty-eight rules) or a per-rule source-text reconstruction table in Mathinline::process, neither of which is a local edit to Mathinline or the described-Email claim, and either risks the settled behavior of every other rule that can sit inside math. The suppression set is also four rules wide, not the two named in the current Mathinline comment, so a partial edit would leave the battery red. The candidate is therefore recorded with its full evidence for the programme's correction round rather than patched in-tree.

The mirror consequence for the coordinator's adoption pass: mathResolve in lean-ftml/LeanFtml/Inline1Rules.lean transcribes the one-level, option-value fold and mathRepl returns no bytes for an OptVal.bytes text option, so both halves of the mirror disagree with live on the divergent rows; the MATCH rows remain valid regression pins. No ftml file was edited, no cargo was run, no git identity or commit was used, and no live probe was reused without its validity recorded here.
