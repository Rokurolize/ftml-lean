THE SAVED PAGE IS THE ORACLE. A construct's live behavior is what a saved page renders. CAPTURE DISCIPLINE. (1) Capture each saved page with two independent anonymous GETs; if the two renders differ, the capture is not stable and must not be used as evidence, re-capture later instead of picking one. (2) After saving, read the page back and confirm saved_source_matches (the stored source byte-identical to the intended source); a save that landed differently invalidates everything downstream. (3) Verify source identity by sha256 of the source bytes, not by eyeballing text. (4) Page views are fetched anonymously, never through the credential-bearing client; wikidot-probe capture already works this way. (5) Mask per-render noise before comparing: Wikidot injects values that change every fetch (random tab and tabview element ids, data-delta and data-timestamp attributes on [[date]] output). wikidot-probe norm is the standard masking; import it rather than re-deriving it. (6) The empty-save quirk: re-saving a page with no changes can make Wikidot re-parse syntax that was transiently misparsed, fixing rendering artifacts; before concluding a page's source syntax is wrong, try an empty re-save and re-capture.
