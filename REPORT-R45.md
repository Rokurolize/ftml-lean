## 3. Mirror structure, per rule

No enumeration discipline is needed for this family, and none is used. The R3.10 lesson does not transfer: Tableadv's parse side enumerates because its grammar is ambiguous, but all four render functions here are flat per-token functions with no recursion over document structure at all. List rendering does not walk a nested item tree in the renderer; the parse rule encodes the entire nesting in the token stream (the `level`, `count`, `in_sublist`, and `tail` options, the `sublist_start` / `sublist_end` wrapper tokens for skipped depths, and the explicit-block token family), so the renderer is a switch over the token's `type`, exactly as the PHP body is. Every characterization theorem is therefore a plain `rfl` computation on a concrete option map, empirically verified by the build (§8); the single place a plain `rfl` could have hit the kernel cost R4.4 recorded for `utf8Valid` inside an escape is the explicit-list attribute value, and the value characterized there is one byte, measured firsthand to reduce trivially (the isolated escape equality and the whole theorem each check by `rfl` in well under a second), so no proof device is disclosed for this stage.

**List** (`renderList`). Exactly which render-time state this rule reads: its own token's options only, plus the four css confs (`css_ol`, `css_ol_li`, `css_ul`, `css_ul_li`), all null under the harness, so every `formatConf` is empty. The native branches mirror as: `bullet_list_start` → `"<ul>\n"`, preceded by `"\n"` iff `level > 0` and `in_sublist` is PHP-empty (the child list opens on a new line inside its parent item, except inside a depth-skip wrapper); `number_list_start` → the same with `<ol`, plus the `format` type attribute (never set by the active parse; mirrored for totality, interpolated raw exactly as the PHP body interpolates it) when `format` is set and non-empty; `bullet_list_end` / `number_list_end` → `"</li>\n</ul>"` (resp. `</ol>`) when the token's `tail` is not `'sublist'`, `"</ul>"` when it is, with a trailing `"\n"` iff `level > 0` or (`level === 0` and the tail is a sublist); `sublist_start` → `"<li style=\"list-style: none; display: inline\">\n"` and `sublist_end` → `"</li>\n"` (the inline wrapper for a skipped depth); item starts → `"<li>"`, preceded by `"</li>\n"` iff `count > 0` (item endings are emitted by the next item start or the list end); item ends → the empty string. The mirror reproduces the PHP body's extracted-value semantics for `level` (an absent `level` is `null`, which is neither `> 0` nor `=== 0`) rather than defaulting it. The explicit-block branches (the refgaps M46 family) mirror as: `explicit_list_start` → `"<" ++ (list_type == 'ol' ? 'ol' : 'ul') ++ attrs ++ ">\n"` and `explicit_list_end` → the matching closer plus the token's `trail` bytes, where `attrs` is the token's stored attribute map rendered pair by pair as ` key="value"` with values escaped by `htmlspecialchars(..., ENT_COMPAT)` (the renderer's own `renderAttrs`), in stored order; `explicit_item_start` → `"<li" ++ attrs ++ ">" ++ lead`; `explicit_item_end` → `lead ++ "</li>\n"`; `explicit_none_item_start` / `_end` → `"<li style=\"list-style: none\">"` / `"</li>\n"`; `explicit_inline_wrapper_start` / `_end` → the sublist wrapper opener / `"\n</li>\n"`; `explicit_br_no_nl` → `"<br />"`; `explicit_raw_nl` → `"\n"`; `explicit_empty` and any other type → the empty string. The wrapper tokens' `newline` / `lead_nl` options are parse-side bookkeeping the renderer never reads; the fixed strings above are what it emits.

**Deflist** (`renderDeflist`). Reads only the token's `type` and the three null css confs. The six types are fixed strings: `list_start` → `"<dl>\n"`, `list_end` → `"</dl>\n"` (exactly one newline, the R2 C1 correction), `term_start` → `"<dt>"`, `term_end` → `"</dt>\n"`, `narr_start` → `"<dd>"`, `narr_end` → `"</dd>\n"`; any other type → the empty string.

**Table** (`renderTable`). Reads its own token's options and the render confs, of which the harness sets exactly one in this family: `css_table = 'wiki-content-table'`, so `table_start` carries ` class="wiki-content-table"`; `css_caption`, `css_tr`, `css_th`, and `css_td` are null. The free `format` fragment (`isset` semantics: present and non-null, rendered with a leading space) is caller-supplied and never set by the active parse; it is mirrored anyway, as is the `rowspan` option, which the parse never emits (the renderer's default of 1 then applies). The branches mirror as: `table_start` → `"<table class=\"wiki-content-table\"" ++ format ++ ">\n"`; `table_end` → `"</table>"`; `caption_start` → `"<caption" ++ format ++ ">\n"`; `caption_end` → `"</caption>\n"`; `row_start` → `"<tr" ++ format ++ ">\n"`; `row_end` → `"</tr>\n"`; `cell_start` → `<th` iff the `attr` option equals `'header'`, else `<td`, then ` colspan="N"` iff `span > 1`, then ` rowspan="N"` iff `rowspan > 1`, then ` style="text-align: <attr>;"` iff the attr is neither `'header'` nor empty, then the format fragment and `>`; `cell_end` → `"</th>\n"` for a header attr, else `"</td>\n"` (the newline after a cell end is live truth, kept by the R2 C1 correction). The mirror coerces a `null` attr (the parse's plain-cell shape) to the empty byte string, which reproduces the PHP body's loose comparisons exactly: `null` is neither `== 'header'` nor `!= ''`, so a plain cell gets no style.

**Tableadv** (`renderTableadv`). Reads its own token's options; the conf array is empty. Following the PHP body, the attribute fragment is computed before the type dispatch: each pair of the token's `attrs` map renders as ` key="value"` in stored order (the parse stores the attributes sorted by name, `ksort` in `buildAttrs`), each value cast to string and escaped with `htmlspecialchars(..., ENT_QUOTES | ENT_SUBSTITUTE)`. The cell tag is `th` iff the token's `header` option is PHP-truthy (set from the authored closer name at parse). The branches mirror as: `start` → `"<table" ++ attrs ++ ">\n"`; `rowStart` → `"<tr" ++ attrs ++ ">\n"`; `cellStart` → `"<" ++ tag ++ attrs ++ ">"`; `cellEnd` → `"</" ++ tag ++ ">\n"`; `rowEnd` → `"</tr>\n"`; `end` → `"</table>"`; any other type → the empty string.
