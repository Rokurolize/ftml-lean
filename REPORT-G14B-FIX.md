# REPORT-G14B-FIX: include argument-splitting model corrected to live's raw-pipe semantics

The comment-aware segment split that GRAMMAR-INCLUDE.md G4 stated, the reference PHP implemented, and the Lean conformance driver implemented is corrected everywhere to live's comment-unaware semantics: the argument tail splits on raw `|` bytes, `[!-- ... --]` bytes are ordinary value bytes, a pipe inside a comment splits the segment there, and an unterminated comment is ordinary text that cannot fail the block. The settling evidence is the AUDIT lane's live probes muse-probe-audit-g14b-cmt-pipe and muse-probe-audit-g14b-cmt-unclosed (audit-g14b/captures.json, valid, stable, saved_source_matches), read firsthand by the coordinator before this lane was briefed. The sequential fold (LeanFtml.IncludeExpr) is untouched, as the brief required: the defect was in segment scanning only, and the audit's other eighteen cases confirm the fold.
