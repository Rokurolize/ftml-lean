# REFCORR8 design decision — the round-5 reference and mirror corrections (2026-11-23)

This is the design record for REFCORR8, modelled on REFCORR7-DESIGN.md and written from the 17 intake confirmations in REFCORR8-INTAKE.md. It is a draft for the coordinator and the nine mechanism units: this documentation unit changed no canonical, reference, mirror, spec, pin or gate file, ran no Lean and fetched no probe. Live Wikidot behavior remains definitional, the evidence order is ftml pins then frozen parity captures then the already-cached single-fetch live probes, and the nine minimal mechanisms below are deliberately independent so a narrowing or rejection in one bucket cannot silently move another bucket's cases. The bucket map is R8-A=4 list shapes, R8-B=3 Freelink whitespace shapes, R8-C=2 empty-Raw re-trim shapes, R8-D=2 Math/Mathinline shapes, R8-E=1 four-adjacent U+FFFD shape (conditional on the intake digit-canonization decision), R8-F=1 Raw 4+3 shape, R8-G=1 Tableadv data-* shape, R8-H=2 Div parse shapes and R8-I=1 Div render id shape, totaling 17.

The live rules established by the 17 confirmations are the following. For R8-A, opener and closer case is not symmetric: a scored uppercase opener with [[li]] items stays unclosed and truncates at end of page, an uppercase opener with no item and no closer is preserved as literal prose, a mixed-case opener with class/id/data attributes followed by a nested lowercase list and a cross-type uppercase closer yields two sibling lists with the tail outside, and a cross-type uppercase closer at depth two leaves literal item and list closers on live. For R8-B, the `_default:` category strip tolerates exactly the three evidenced leading bytes U+000B, U+00A0 and U+3000 before the prefix, while the byte-zero, non-leading and generic-colon controls behave as the reference already does. For R8-C, after the REFCORR7 empty-Raw strip the remaining whitespace must be re-trimmed, so a footnote body of two empty Raw tokens separated by whitespace serves `>1</a>.</div>` and the same bibliography value serves `1.</div>`, with the whole ASCII-whitespace class covered by the follow-up rows. For R8-D, an uppercase Math attribute name `TYPE="align"` selects the equation environment on live against the reference's case-sensitive align default, and a Date token inside a Mathinline source span suppresses the whole formula to `$$` rather than being silently dropped. For R8-E, the four-adjacent empty-Raw run after a literal U+FFFD leaks a different index string on live and reference while the two- and three-placeholder siblings match; the disposition of the digit string is the intake decision above. For R8-F, a 4+ Raw opener followed on the same line by a three-byte closer run preserves the three literal @ bytes. For R8-G, a mixed-case `data-Foo` attribute key is lowercased to data-foo and kept, while all-uppercase or non-data keys stay dropped. For R8-H, a whitespace-only div class stays a real empty div with an empty class attribute, and after case folding the later authored data-* value overwrites the earlier one. For R8-I, a whitespace-only div id that isolates to the bare `u-` shell is emitted verbatim rather than cleared.
