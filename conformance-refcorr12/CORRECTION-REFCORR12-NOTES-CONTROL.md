# CORRECTION-REFCORR12-NOTES-CONTROL — keep ESC, drop the live-discarded C0 set, and drop Bibliography FF before the whitespace fold (2026-11-23)

This is a mechanism-unit draft for the coordinator to place at conformance-refphp/notes/CORRECTION-REFCORR12-NOTES-CONTROL.md after adoption; it changes no canonical file itself. It supersedes the width of the REFCORR11 GENERAL-CONTROL rule for notes bodies after round 5e confirmed two residual defects on the post-REFCORR11 ground. C-R5E-P4-1 (REPORT-ROUND5E-P4.md, witnesses R5E-P4-C05 and C08) and C-R5E-S1-2 (REPORT-ROUND5E-S1.md, witnesses S10 and S11) show that live Wikidot keeps ESC 0x1B verbatim in a footnote body, while the REFCORR11 filter class [\x00-\x08\x0B\x0C\x0E-\x1F] drops it. C-R5E-S1-3 (witness S12) shows that Bibliography.php:84 folds a form feed to an ordinary space before Tighten.php:99 can drop it, so live emits `[[bibitem k]]AB[[/bibitem]]` where the reference emits `[[bibitem k]]A B[[/bibitem]]`. All evidence is the already-cached round-5/5b/5c/5d/5e captures and conformance trees; no new live probe was fetched.

The general control-byte rule for notes bodies. Let D be the live-discarded C0 set, every byte below 0x20 except TAB 9, LF 10, CR 13 and ESC 27, i.e. [\x00-\x08\x0B\x0C\x0E-\x1A\x1C-\x1F]. ESC is NOT in D and is kept wherever live keeps it; D is dropped unconditionally at parse time from a footnote body, a bibitem body and a Bibliography residual line, before the authored-break decision, the empty-Raw visible projection and the \s+ whitespace fold are evaluated. Concretely: (1) Footnote.php:66 and Bibitem.php:59 use the narrower class D instead of REFCORR11's 0x0E-0x1F upper range, so VT, FF and the rest of D are still dropped on every branch while ESC survives; (2) Bibliography.php:84 drops D from the residual line immediately before preg_replace('/\s+/', ' ', $text), so FF and VT vanish as controls instead of becoming spaces that the later Tighten drop cannot remove, while TAB and CR are kept and still fold to one space. The REFCORR10 authored-break predicate still decides only empty-Raw placeholder retention, so the R3D-F3 single-break witness keeps its <br />. Stored vars['bibitems'][$label] state and all token wire shapes are unchanged; no compared field is added, and the render side in Footnoteitem.php and NotesRender.lean stays unchanged because the stored bodies are already control-pure. The mirror is symmetric: NotesRules.isLiveDroppedControl narrows to b < 32 && b != 9 && b != 10 && b != 13 && b != 27 (the same class as Inline3Rules.isDiscardedControl), and NotesRules.collapseWs applies stripLiveDroppedControls before the whitespace collapse.
