Capture s2f-10-lead-esc-control, fullname muse-probe-round5f-s2-s2f-10-lead-esc-control, valid=true, stable=true, saved_source_matches=true, html_sha256 f365d5c54ea25bc0fb7bcba5523e4ca8278e7ebdecb4e36571015b74cdf3d6c5; the stored source is byte-identical to the intended `[[[\u001b_default:x]]]` with a single U+001B ESC byte, sha256 065257c43f89d21742e08621179e9578a953bb7fc1edd5bdcb9fb3fe4a6d72f3, so this is not a save-normalized UNTESTABLE case.

Decisive live bytes after probe.norm and the campaign frame mask: `<p><a href="/x">x</a></p>` (the `class="newpage"` serving class is masked and is not part of the disagreement). Reference bytes, ref.jsonl line 10: `<p><a href="/default:x">x</a></p>`. The href page value differs on a rule-level field; this is neither an inter-tag newline, a token-id counter digit, an iframe or gallery serving surface, nor a Math PNG boundary. A supplementary `php harness/batch.php tokens` run (probe-tokens.jsonl, exit 0, zero stderr) shows the reference token is `["Freelink",{"page":"default:x",...}]`, confirming the divergence is in the parse rule and not in the render.

Owning reference file: ref-php/text-wiki/Text/Wiki/Parse/Default/Freelink.php, whose REFCORR12 general lead predicate at line 213 admits only Unicode Cf, Unicode White_Space, U+FEFF and U+002A, so U+001B (general category Cc, not White_Space) is left in the slug and `_default:` is not stripped. Live strips the ESC byte before the category prefix and serves page x. The REFCORR12 correction record explicitly assumed that byte-zero NUL and every other C0 or C1 control outside those sets are live-rejected; this fresh probe shows that assumption is false for ESC, which live admits as a lead. No prior round exercised an ESC lead: the 357-source REFCORR11 union plus round-5/5b/5c/5d/5e cases audited by R12-FREELINK contains zero ESC-plus-_default sources, and the CR and NUL siblings were save-normalized UNTESTABLE in the S2 lineage.

Mirror consequence inferred by source reading, not claimed as an elaboration: lean-ftml/LeanFtml/LinkRules.lean line 1066 defines `isDefaultLeadCp cp := cp != 0x00 && (isUnicodeFormatCp cp || isUnicodeWhiteSpaceCp cp || cp == 0xFEFF || cp == 0x2A)`, which likewise excludes 0x1B, so the mirror would keep ESC in the page name and carry the same divergence.
