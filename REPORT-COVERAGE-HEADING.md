# REPORT-COVERAGE-HEADING: coverage-tier classification of the heading family

This lane brings Heading, Toc and Anchor, across parse and render, to the coverage standard of the prose, notes and inline families: a formal input classification taken from the reference's own decision structure, a Lean proof that the classification is complete over that structure, a pin for every class, and seeded within-class fuzz against the reference on two seeds. The classification is read from the current mirror in this tree, which is the canonical programme tree after the REFCORR4, TABLEADV-FIX, REFCORR5, COVERAGE-INLINE, MIRROR-FIX and REFCORR6 adoptions: `LeanFtml/BlockRules.lean` (`headingMatchLine`, `headingProcess`, `tocMatchAt`, `tocProcess`, `tocItems`), `LeanFtml/RawHeadingRules.lean` (`renderHeading`, `renderToc`), `LeanFtml/FinalRules.lean` (`namedAnchorProcess`, `anchorElemProcess`, `buildAnchorAttrs`) and `LeanFtml/InteractiveRules.lean` (`renderAnchor`), cross-read against `ref-php/text-wiki/Text/Wiki/Parse/Default/{Heading,Toc,Anchor}.php`, `Render/Xhtml/{Heading,Toc,Anchor}.php` and the Toc NUL post-pass in `Text/Wiki.php`, under the harness configuration in `ref-php/harness/wiki-config.php` (`css_h*` null, `use_id` true, Toc `div_id` = `toc`, `$min` = 0). Live Wikidot behavior is definitionally correct, however malformed. The evidence order was (1) the ftml corpus and integration pins, (2) the frozen parity captures and the retained batteries, (3) fresh reference probes, fetched once through `conformance-covheading/driver.php` and reused. No ftml file was edited, no cargo was run, no repository-local git identity, identity environment variable or `-c user.*` override was set, and `Main.lean` was not edited. Every Lean invocation went through `~/.local/state/wikijump/muse-bhl/tools/lean-build.sh`, strictly one at a time; the scratch elaboration `lean-ftml/CovHeadingAxiomAudit.lean` is uniquely named and inside this tree, and no `lean` or `lake` command was invoked directly.

The formalization is `lean-ftml/LeanFtml/CoverageHeading.lean`, imported from `LeanFtml.lean` by an appended import. The audit `#print axioms` lines are staged at the tree root in `coverage-heading-audit-block.txt` for the coordinator to merge. `HeadingClass` is an inductive enumeration of 78 branch classes; `navAllClasses_length` proves the count and `navAllClasses_nodup` proves the enumeration has no duplicates. The collision check before naming: this file uses `navClassify` and `HeadingClass`. It does not reuse `classify` (`CoverageProse.lean`), `NotesClass` (`CoverageNotes.lean`) or `InlineClass` (`CoverageInline.lean`). `HdLevel` is local and is not `Depth.lean`'s depth.

The input side is `NavShape`, one sum covering both parses and renders. A heading line is `HdParseShape`: miss, or one of six levels with the `*` / no-`*` flag (`hasToc` is true when the star is absent). `hdParseShapeOf` copies the guards of `headingMatchLine`, so a run of seven pluses, a missing space, and any other residual are the miss. A Toc source is `TocParseShape`: miss, or one align value of the match array (`null` when group 1 is absent, `empty` when a later group participated and the float is empty, `f<`, `f>`). An item is `TocItemShape`, keep when the type is exactly `start` and skip otherwise, which is the `tocItems` filter; the counter `count` increments and is never read by `renderToc`. A named anchor is `AnNameIn`: placeholder when the name contains `0xFF` (REFCORR4 C-SUSPECT-XRULE-6), blank when the name trims empty, valid when every byte is in `[-_A-Za-z0-9.%]`, literal when the residual `]` participated and the match is not preceded by `[`, otherwise invalid. An element is `AnElemIn`, the exclusive form after `anchorElemProcess` (nested, paragraph, scored, plain) plus the composing modifiers (lead, trail, nested closer, join-strip, href kind, star-blank target, id kind, fixed-key kind, data-key kind, other-key drop). Heading, Toc and Anchor render are `HdRenderShape`, `TocRenderShape` and `AnRenderShape`, read off the token options the same way `renderHeading`, `renderToc` and `renderAnchor` read them. `navClassify` maps a shape to the list of classes it enables, because the id attribute, the collapse script, the Toc align and title, and the anchor modifiers compose with a unique base class, while the level, the toc flag, the name cascade, the element form, the href kind and the three render type cascades are exclusive.

Completeness over that structure is proved. `navAllClasses_mem` shows every constructor is declared; `nav_classify_sound` shows any emitted class is declared; `nav_classify_nonempty` shows every shape emits at least one class; `nav_witness_classify` supplies a representable shape for each of the 78 classes; `nav_classes_exhaustive` identifies the class set with the image of the classifier; and `nav_classification_complete` bundles decidability, coverage and exhaustiveness. Exclusivity of the cascades that are exclusive is `hd_hit_one_level`, `hd_hit_one_tocflag`, `hd_miss_no_level`, `hd_end_sign_exclusive`, `toc_start_one_align`, `toc_start_one_title`, `toc_end_one_wrap`, `an_name_exclusive`, `an_form_exclusive`, `an_href_exclusive`, `an_render_exclusive` and `toc_item_exclusive`. `hd_hidden_implies_script` records that boolean-true collapse on `startContent` emits the script as well as the hidden div, because `=== true` implies the value is set and `static $jsOutput` is read and never assigned. The partition lifts to a real render token by `navShapeOf`, `navClassOf` and `navMemClass`, with `nav_shapeOf_isSome`, `nav_classOf_complete`, `nav_classOf_sound`, `nav_classOf_exclusive`, `nav_memClass_complete` and `nav_memClass_sound`. Every heading line, every Toc source and every named-anchor name lands in the partition (`hd_every_line`, `toc_every_src`, `an_every_name`). Two shapes are recorded as non-classes: Toc's `xhtmleditable` early return, which the harness format `Xhtml` never takes and which `tocProcess` does not implement, and Heading's `static $jsOutput`.

The heading counter, the id, the depth, the dead `count` and the placeholder arm are closed computations. `cov_hd_toc0_id` and `cov_hd_toc_advances` show a no-star heading takes `tocN` and advances `headlineId`. `cov_hd_notoc_id` and `cov_hd_notoc_counter` show a starred heading stores a null id and leaves the counter where it was. `cov_hd_seven` shows seven pluses are not a heading. `cov_toc_skips_notoc` shows `tocItems` drops `start-notoc`. `cov_toc_count_unrendered` shows `renderToc` ignores `count`. `cov_toc_depth_level1` shows a level-1 item is included at `margin-left: 1em`, with `$min` constant 0, so a skip is only a gap. `cov_toc_sentinel_width` shows the mirror's marker is four NUL bytes. `cov_toc_null` shows a bare `[[toc]]` is the absent-group arm, and `cov_toc_empty` shows `[[toc]]` followed by a newline is the empty-string arm. `cov_an_placeholder` shows a name containing `0xFF` returns the whole match and claims no token.

The fuzz is seeded and within-class. `conformance-covheading/run_fuzz.py` draws six variants per class per seed (seeds 20261122 and 7), varying only decision-irrelevant text: the heading words, the anchor bodies, the level inside a render token, and a trailing character on the Toc regex. A token case is one Heading, Toc or Anchor token, the reference `token()` through `driver.php` under `ref_configure_wiki` against `lean-ftml-conformance-r48 state`, and it passes when the bytes match and the independent PHP class list equals the generator's list. A source case is a page through the reference `transform` against `--e2e-r48`, and it passes when the HTML matches and the reference tokens satisfy the class predicate. The `tocPNull` cases are the regex half: `preg_match` of the Toc pattern must succeed with group 1 absent. They are not render byte-identity, and they are not counted as such. The page half of `tocSentinel` is `+ **word**\n[[toc]]`, which checks that the heading keeps its `<strong>` and the TOC entry does not.

Seeds 20261122 and 7 gave 480 cases each, 960 in total. Each seed has 6 regex checks, all of which passed, and 474 byte comparisons, of which 456 passed and 18 failed. The 18 failures are the raw item tokens of `tocRItem`, `tocRItemEnd` and `tocSentinel`, and each one differs only by a two-NUL run against a four-NUL run. Independent PHP class annotation agreed with the generated expectation on every token case: zero class mismatches. No case was uncomparable. All generated cases, both sides' outputs, the per-class tallies and the failure records are retained under `conformance-covheading/` (`fuzz-cases-<seed>.jsonl`, `php-<seed>.jsonl`, `lean-<seed>.jsonl`, `fuzz-summary-<seed>.json`, `disagreements-<seed>.json`, `fuzz-run.log`, `fuzz-summary.json`).

## Named remainders

R-1 (token-grain width, page HTML agrees): the Toc item sentinel. `Render/Xhtml/Toc.php` emits two NUL bytes on `item_start` and on `item_end`, and `Text/Wiki.php` strips with `/$d$d(.*?)$d$d/s` then `strip_tags`. The mirror emits `tocStripDelim`, which is four NUL bytes, and `postStripToc` looks for four and four. Each side's emitter matches its own stripper, so a real page agrees: `+ **hi**\n[[toc]]` renders the same HTML on both sides, the heading keeps `<strong>hi</strong>`, and the TOC entry is `hi` with the tags removed. The six page cases inside `tocSentinel` pass. The eighteen raw token cases per seed fail, and the failure is exactly that width. `cov_toc_sentinel_width` records the mirror's four bytes. This lane does not edit the mirror. The class stays, pinned by `toc11-inline-markup`, `muse-probe-suspect3-m3-t4a`, `muse-probe-suspect-xrule-x31-toc-ustrip` and the closed theorem.

R-2 (regex arm, not a page outcome): `tocPNull`. On the Toc pattern alone, `[[toc]]` and `[[toc]]text` leave group 1 unset, and `tocProcess` stores a null align. A full pipeline page does not reach that arm: Prefilter supplies a newline, the trailing group participates, and the saved align is the empty string, which is `tocPEmpty`. Null and empty render the same, because both are falsy and both wrap the table. The six cases per seed check the regex arm only. The Lean side of the arm is `cov_toc_null`. The empty-string arm is page-reachable and is pinned by `toc01-before`, `toc03-empty` and `muse-probe-suspect3-m3-t3c`.

R-3 (no page pin): the parser never emits a collapse option, never emits `startContent` or `endContent`, never emits a Toc align other than `f<`, `f>` and the two falsy values, and always stores an attribute map on an Anchor start. The classes that live only on those direct calls are `hdROnclick`, `hdREndMinus`, `hdREndPlus`, `hdRContent`, `hdRContentEnd`, `hdRScript`, `hdRHidden`, `hdRFall`, `tocROther`, `tocRFall`, `anRStartDefault` and `anRFallName`. Each has a designed token in the inventory and six token cases per seed, all of which matched the reference. `hdRStart` itself is page-reachable; the combination of `start` with no id is the direct-call shape inside that same class, and the fuzz covers it.

R-4 (dead branch, non-class): Toc's `xhtmleditable` early return is not in the partition. The harness format is `Xhtml`, and `tocProcess` has no such arm. Heading's `static $jsOutput` is read and never assigned, so a collapse-set `startContent` always emits the script; `hd_hidden_implies_script` is that fact, and the script is the class `hdRScript` rather than a second, unreachable branch.

## Closing accounting

The family's input classification is proved. On a real Heading, Toc or Anchor token `navClassOf` is total and `navMemClass` is that function read as a decidable predicate; the exclusive cascades are proved exclusive and the modifiers compose with their unique base class. Every heading line, every Toc source and every named-anchor name lands in the partition. Every one of the 78 classes has a live probe, a retained battery pin, a closed computation, or a recorded reason with a designed direct-call pin. The seeded fuzz agrees with the reference on 456 of 474 byte comparisons per seed; the 18 disagreements are the sentinel width of R-1, and the six regex checks per seed are the `tocPNull` arm of R-2. No other class failed. The counter, the id, the unrendered `count`, level 1 in the TOC, the seven-plus miss and the placeholder name are closed theorems, and SUSPECT3's depth and numbering seams are the same branches. Live Wikidot behavior remains definitionally correct: the reference is not changed to hide R-1, and the mirror is not edited.
