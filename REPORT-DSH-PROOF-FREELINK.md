## 1. Inherited draft and keep/drop adjudication

The handed-over draft was `lean-ftml/LeanFtml/FreelinkProof.lean`, 1005 lines, introduced by the WIP handover commit `c806947` ("WIP handover: freelink proof lane draft as-is (Cursor lane paused)"). Its stated aim was already close to this brief: `isDefaultLeadCp` as a finite roster, canonical UTF-8 decoding by `leadCpLen`, maximal lead-run consumption by `skipDefaultLead`, the two-hash and leading-hash literal guards, and the `_default:` slug reflection, plus closed `decide` witnesses for the REFCORR11/5e Cf leads and the hash/route shapes.

The programme policy classifies Freelink as the single Unicode-`/u` Class B parse rule (ADVISOR-PROOF-POLICY.md §2.2, "Unicode `/u` Parse Rules" row) whose full target is a `UnicodeCore` + `PcreCore` consumer, and its §4.3 lane table names **no keeper** for `proof/freelink`: the keep cell is "— (clean start)", with a new target only after F2 (`PcreCore`) and F3 (`UnicodeCore`) land. This brief's mission explicitly puts full Class B universality out of scope and asks instead for the lead-class laws and placeholder/reflection behaviour that do not wait for those kernels. Those two statements are consistent: the policy's "clean start" is keyed to the post-kernel target, which is not this lane's current target.

Adjudication performed: **dropped the inherited draft wholesale** (the file was removed), because the policy names no keeper for this family and because the draft does not elaborate against this branch's mirror. With the tracked `.lake` oleans refreshed from source, the draft produced 42 elaboration errors: its guard-chain splits assumed a different guard order and an older `skipDefaultWsBytes`/`starLead` mirror shape, and its `leadCpLen_encode` arithmetic had concrete mistakes (for example `(128 + cp) % 64` where `(128 + cp % 64) % 64` was required, and a reversed `Nat.div_div_eq_div_mul` direction). Its intent was retained as the target list for a fresh set of proof units at the policy's mandated module path `lean-ftml/LeanFtml/Proof/`; no draft theorem text was carried over.

The work was then divided into disjoint proof files, each owned by one teammate on the shared task board: `FreelinkLead.lean` (opener recognition), `FreelinkSkip.lean` (UTF-8 decode and skip mechanism), `FreelinkGuards.lean` (placeholder and hash guards), `FreelinkDefault.lean` (reachable-domain reflection), plus `FreelinkSlug.lean` (toUnixName invariant). `LeanFtml/Proof/Freelink.lean` is the family aggregator. Import wiring into `LeanFtml.lean` / `Main.lean` is deliberately left to the coordinator at adoption, per the brief's boundary.

## 2. Proved and certified

All files below are new, live under `lean-ftml/LeanFtml/Proof/`, import only the mirror modules (`LeanFtml.LinkRules`, `LeanFtml.ServingRules`), and state properties of the mirror's own functions. `LeanFtml/Proof/Freelink.lean` is the family aggregator that imports all eleven units.

Openers and the lead class. `FreelinkLead.lean` proves `isDefaultLeadCp_iff_mem`: the mirror's predicate is exactly membership in a 29-point roster (ASCII White_Space plus `*`, U+0085, U+00A0, U+1680, U+2000–U+200B, U+2028, U+2029, U+202F, U+205F, U+2060, U+3000, U+FEFF). It proves that no lead is an ASCII letter, every `freelinkSchemes` head is a letter, `byteCiEq` cannot match a non-letter head against a letter, and therefore `isUrlTarget` is false on any non-letter-headed target and on nil. Eight closed `decide` witnesses pin the REFCORR11/5e Cf admissions and exclusions. `FreelinkMatch.lean` proves the opener-recognizer facts: no `[[[` opener gives none, and every `some (full, g1, label, rest)` satisfies `full ++ rest = src`, a nonempty all-free target group, and a label that is empty or a pipe followed by all-free bytes; it also proves the candidate-level present-before-absent priority. The stronger claim that every well-formed `[[[target|label]]]` yields that exact label is false without `124 ∉ target` (a shorter candidate with its own pipe can legitimately win); this was identified and not claimed.

UTF-8 and the lead-run mechanism. `FreelinkSkip.lean` proves `leadCpLen_bound`, canonical decoding `leadCpLen (encodeCp cp ++ rest) = (cp, len)` for all roster members, fuel-independence of `skipDefaultLeadFuel`, maximal lead-run consumption by `skipDefaultLead`, the stop cases, and the `_default:` strip law. `FreelinkDefaultAllLeads.lean` re-proves the skip, strip and URL-exclusion pieces with an explicit canonical encoder for the **full 29-code-point lead class**, conjoined in `freelinkDefaultAll_pieces`.

Placeholder and guard behaviour. `FreelinkGuards.lean` proves that a 0xFF placeholder anywhere in the match, a raw with more than one `#`, a `##` substring, or a leading `#` with a non-space second byte each force the literal return `(full, toks)`, together with the `findSub`/`filter`/`any` helpers these need. Closed regression witnesses cover the named REFCORR11 hash and route/anchor shapes.

Reachable-domain reflection. `FreelinkDefaultToken.lean` proves the full token-shape law with **no remainder**: for a trim-lead run followed by `_default:` and an ASCII, hash-free, placeholder-free suffix, `(freelinkProcess full raw [] []).2` is exactly one `Freelink` token and its `page` option is `some (textVal (toUnixName suf))` (byte-list and code-point-framed forms). `FreelinkDefault.lean` retains the isolated slug law that led there. `FreelinkRoute.lean` proves universal `findSub` locators and the exact route/anchor/plain peel components; the anchor form correctly carries an explicit "no earlier `/#/`" hypothesis, since a hash-free prefix ending in `/` followed by a suffix starting with `/` really forms a route. `FreelinkLabel.lean` proves the mirror's own label selectors for empty, bare-pipe and other nonempty labels, and the resulting `omGet` "text"/"textFromTitle" values on the mirrored local option map. `FreelinkSlug.lean` proves the full mirror invariant `∀ bs z, z ∈ toUnixName bs → isSlugByte z = true`. `FreelinkRender.lean` proves that every `renderFreelink` branch emits the `<a` opener, the URL and local existing/newpage branch shapes with falsity of `url`/`site` deciding the branch, and read-key congruence of the renderer.

Honest in-lane gaps, all recorded in file headers rather than papered over: the full-lead-class process-level token equality is not composed (guard alignment for the encoded lead run, the `starUrl` tail case, and final opts assembly remain); the label theorems characterize the mirror's branch selectors and option lookups rather than the whole `freelinkProcess` result; the route unit proves peel components but not the final token options; the render shapes leave `htmlSpecialCharsCompat`/`phpTrimBytes`/`nbspSpaces` subterms abstract and have no closed `decide` witnesses (full-renderer witnesses exceeded the wrapper runner's wall cap). These are the strongest forms the current tree supports within this lane's mandate; none is relabelled as a universal proof.

Registry, regression witnesses, and universal theorems are kept in the same files but are labelled distinctly: the closed `decide`/`rfl` checks are regression pins, not counted toward the proof claims.

## 4. Recorded mirror/reference divergence (witness, not repaired)

The mirror's `leadCpLen` decodes any well-formed-looking three-byte sequence, and `isDefaultLeadCp` then tests the decoded code point. The reference rule's lead class (ref-php `text-wiki/Text/Wiki/Parse/Default/Freelink.php`, line 240) is a **byte-oriented** alternation: `[09..0D 20 2A] | C2[85 A0] | E1 9A 80 | E2 80[80-8B A8 A9 AF] | E2 81[9F A0] | E3 80 80 | EF BB BF`. On canonical UTF-8 the two admit exactly the same 29 code points. They separate on an overlong encoding:

Minimal witness bytes: `E0 82 A0 5F 64 65 66 61 75 6C 74 3A 78` (overlong U+00A0 followed by `_default:x`). The mirror computes `leadCpLen [E0,82,A0] = (0xA0, 3)` and `isDefaultLeadCp 0xA0 = true`, so it strips the lead and the `_default:` prefix and returns page `x`. The reference alternation has no `E0` branch, so it does not strip and the slug stays `_default:x`. This is the same witness the inherited draft recorded as `overlong_nbsp_decoded` / `overlong_nbsp_page`; it was re-derived here by reading both predicates, with no live probe fetched. It is recorded, not repaired: source fixes belong to the coordinator's correction rounds. The proof units are statements about the mirror's own functions, so they remain valid regardless of how this witness is adjudicated.
