The general rule. The final Tighten parse pass drops the exact discarded C0 byte set that live's purifyHtml removes from residual plain text: 0x00-0x08, 0x0B, 0x0C, 0x0E-0x1A and 0x1C-0x1F. TAB (0x09) is already folded by the horizontal-run collapse, LF (0x0A) is already removed by the fossil newline deletion, CR (0x0D) is kept, and ESC (0x1B) is deliberately kept — this is precisely the class in the ftml scanner (`is_discarded_control`) and in this reference's own Size rule, and the D7 control (`[[size 12px]]A\x1bB[[/size]]`, cached live=ref CLEARED) proves ESC must not be dropped. The drop is applied to the residual source only; token placeholders hold just 0xFF and digits, so no token body is touched. This mirrors the REFCORR10 footnote-body C0 drop at the final seam so both paths agree on live's character class. The earlier footnote helper uses a slightly wider class that also drops ESC; this unit leaves that adopted code untouched because no live ESC-in-footnote evidence exists, and records the difference as a caveat.
